⚡ Real RESTful Web Service Endpoints

This application implements standard REST constraints with HTTP verbs, JSON payloads, and HTTP status codes.

POST /api/refills Creates a new refill record in MongoDB 201 Created
GET /api/refills Retrieves all household refill records 200 OK
GET /api/refills/{id} Retrieves a single refill by primary key ID 200 OK / 404
PUT /api/refills/{id} Updates all attributes of an existing refill record 200 OK / 404
PATCH /api/refills/{id}/status Partially updates refill status (e.g. marks as 'Refilled') 200 OK / 404
DELETE /api/refills/{id} Permanently removes a refill from MongoDB 200 OK / 404
GET /api/refills/upcoming Queries approaching refills due within the next 7 days 200 OK
GET /api/refills/search?name=... Performs case-insensitive substring search on product name 200 OK
